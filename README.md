# Wayafee

A guided FXRP on-ramp built for remittance and savings — not generic minting.

Minting FXRP today requires two separate wallets (MetaMask for Flare, Xaman for XRPL), 
a cross-chain payment with an easy-to-miss destination tag, and a multi-minute wait for 
attestation — friction that keeps everyday XRP holders out of Flare DeFi.

Wayafee turns that into one guided flow: connect both wallets, send XRP with the payment 
details handled for you, watch real-time status as your FXRP mints — and optionally split 
the incoming funds straight to saved contacts, so the first mint already does what a 
remittance actually needs.

Built for XRP holders in emerging markets — Nigeria specifically — who want to move value 
cross-border or protect savings from currency volatility, but have never crossed into 
Flare DeFi because the mint flow is opaque.
